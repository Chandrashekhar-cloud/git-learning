# 🛠️ Git Commands Practiced

## 📂 Repository Initialization

```bash
git init
git clone
git status
```

## 📌 Staging & Commit

```bash
git add .
git commit -m "Initial commit"
git log
```

## 🌿 Branching

```bash
git branch
git checkout
git checkout -b feature-branch
git merge
```

## ☁️ Remote Repository Commands

```bash
git remote add origin
git push
git pull
git fetch
```

## 🔄 Collaboration Commands

```bash
git stash
git rebase
git reset
git revert
```
